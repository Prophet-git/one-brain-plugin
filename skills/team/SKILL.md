# Teams por carpeta

Es el mismo comando que `/one-brain:cerebro` (un team es lo que antes se llamaba cerebro). Seguí las instrucciones de la skill `cerebro` de este plugin con `$ARGUMENTS`: el ejecutable es `onebrain-team` (o `onebrain-cerebro`, que es el mismo) y el archivo de la raíz del repo es `.onebrain` con una línea `team: <nombre>`.

Listo cuando hiciste lo que pide esa skill para `$ARGUMENTS` (ver, usar o conectar).
